# UCF Study Hub

UCF Study Hub is a LAMP stack web application that allows students to register, log in, upload study notes, search shared notes, edit their own notes, and delete their own notes.

The project follows the required client/server structure by using PHP API endpoints that return JSON and frontend pages that use AJAX/fetch to communicate with the API.

## Features

- User registration
- User login/logout
- Password hashing before storing in the database
- Upload/add study notes
- Search shared study notes
- Edit uploaded notes
- Delete uploaded notes
- User-specific notes page
- JSON API endpoints
- AJAX-enabled frontend
- MySQL database
